# 🎬 Анимации по словам из Twitch‑чата для OBS

Зритель пишет слово в чате — на стриме появляется анимация.

> **Настройка за минуту:** укажите канал → нажмите **«Слушать»** → скопируйте ссылку → вставьте её в OBS.

---

## ✨ Инструкция для пользователя

### 1. Подключите свой канал

1. Откройте страницу проекта в обычном браузере.
2. В поле **«Канал Twitch»** впишите свой логин — тот, что стоит в адресе `twitch.tv/ваш_логин`.
3. Нажмите кнопку **«Слушать»**.
4. Дождитесь статуса: **«Twitch: слушаю #ваш_канал»**.
5. Нажмите **«Копировать»** рядом с готовой ссылкой для OBS.

> Логин пишется латинскими буквами, без `@`, пробелов и отображаемого имени канала.
> После копирования вкладку браузера можно закрыть — OBS подключится к чату сам по этой ссылке.

### 2. Вставьте ссылку в OBS

1. В OBS внизу откройте **Источники → ＋ → Браузер**.
2. Выберите **«Создать новый»**, назовите источник, например **«Анимации чата»**, и нажмите **ОК**.
3. В поле **URL** вставьте скопированную ссылку.
4. Укажите размер области: для анимации на весь экран — **ширина 1920, высота 1080**.
5. Нажмите **ОК** и перетащите источник в списке **выше игры**, чтобы анимации были видны.

### 3. Проверьте

Напишите в своём Twitch‑чате одно из слов:

**`привет` · `здарова` · `давай` · `имба` · `алё` · `лизка` · `лиза` · `лизочка` · `снайпер` · `тройка` · `пока`**

Анимация появится в OBS. Повтор того же слова может сработать не сразу: между анимациями есть короткая пауза от спама.

> **Не видно экран настройки?** Добавьте в конец адреса страницы `?setup=1` и откройте её заново.
>
> **Не работает?** Проверьте логин канала, что источник в OBS включён и находится выше игры, а в свойствах источника нажмите **«Обновить кэш текущей страницы»**.

## Параметры URL

| Параметр | Пример | Что делает |
|---|---|---|
| `channel` | `?channel=ваш_логин` | Twitch-канал для прослушивания |
| `setup` | `&setup=1` | Показать экран настройки и тест-чат |
| `scale` | `&scale=75` | Размер анимации в процентах области источника |
| `fit` | `&fit=cover` | `contain` — вписать целиком, `cover` — заполнить с обрезкой |
| `align` | `&align=bottom` | `center`, `bottom`, `top`, `left`, `right` |
| `durationMs` | `&durationMs=6000` | Длительность по умолчанию, если не прочиталась из WebP |
| `commandsOnly` | `&commandsOnly=1` | Только сообщения с `!` |
| `cooldownMs` | `&cooldownMs=1000` | Пауза между анимациями |
| `sameCooldownMs` | `&sameCooldownMs=30000` | Кулдаун одной и той же анимации |
| `userCooldownMs` | `&userCooldownMs=20000` | Кулдаун одного зрителя |
| `queueMax` | `&queueMax=2` | Максимальная очередь |
| `autoDuration` | `&autoDuration=0` | Не читать длительность из WebP |
| `ignore` | `&ignore=bot1,bot2` | Добавить игнорируемые ники |

## Про размер ваших файлов

Восемь файлов в сумме занимают около 80 МБ. Для GitHub Pages это допустимо, каждый файл меньше лимита загрузки через веб-интерфейс, но есть практический нюанс: страница **не загружает все анимации заранее**. Конкретный WebP скачивается при первом срабатывании, поэтому первый показ большого файла может начаться с задержкой; дальше OBS/Chromium использует кеш.

Если задержки будут заметны, сильнее всего поможет пережатие WebP: ориентируйтесь примерно на 1–3 МБ на анимацию, уменьшив разрешение и FPS до реально видимых на стриме.

## Проверка и проблемы

| Симптом | Что проверить |
|---|---|
| Открывается экран настройки вместо прозрачного фона | В ссылке OBS нет `?channel=...` или остался `setup=1` |
| Статус не становится «слушаю» | В `channel` нужен логин из `twitch.tv/ЛОГИН`: строчные латинские буквы, цифры и `_`, без `@` и пробелов |
| В тесте плашка «файл пока не найден» | WebP нет в репозитории, он лежит не в `asset`, либо имя файла в редакторе/`index.html` отличается хотя бы одной буквой/пробелом |
| Новая анимация не срабатывает | Проверьте в редакторе блок «Проверка слов»; затем убедитесь, что на GitHub загружены и изменённый `index.html`, и сам WebP в `asset` |
| Слово один раз сработало и дальше молчит | Это кулдауны из настроек; для проверки используйте другое слово или кнопку «Тест» на странице — она кулдауны обходит |
| Анимация обрезается или зацикливается | Задайте этому файлу точную длительность в карточке редактора |
| На другой сцене OBS не реагирует | Включено «Shutdown source when not visible» — страница выгружена и не слушает чат |
| GitHub Pages показывает старую версию | Подождите деплой на вкладке Actions; в OBS нажмите Refresh cache в свойствах Browser Source |

Для диагностики откройте ту же ссылку в обычном браузере и добавьте `&setup=1`: там видны статус Twitch, журнал срабатываний, тест-чат и кнопки каждой анимации.

## Структура

```text
index.html        — страница для OBS, экран выбора канала и встроенный список анимаций
instruction.html  — красивая короткая инструкция для пользователя
editor.html       — локальный редактор анимаций и триггеров; изменяет index.html
app.js            — Twitch-клиент, поиск слов, очередь показа
asset/       — ваши Animated WebP
.nojekyll    — отключает обработку Jekyll на GitHub Pages
```

> Никогда не кладите Twitch OAuth-токены в этот репозиторий: GitHub Pages публичен, любой сможет их прочитать. Для данного проекта токены и не нужны.
