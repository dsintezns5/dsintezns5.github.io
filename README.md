# 🎬 Анимации по словам из Twitch‑чата для OBS

Зритель пишет слово в чате — на стриме появляется анимация.

> **Настройка за минуту:** укажите канал → нажмите **«Слушать»** → скопируйте ссылку → вставьте её в OBS.

---

## ✨ Инструкция для пользователя

### 1. Подключите свой канал

1. Откройте страницу проекта в обычном браузере.
2. В поле **«Канал Twitch»** впишите свой логин — тот, что стоит в адресе `twitch.tv/ваш_логин`.
3. Нажмите кнопку **«Слушать»**.
4. Дождитесь статуса: **«Twitch: слушаю #ваш_канал»**.
5. Нажмите **«Копировать»** рядом с готовой ссылкой для OBS.

> Логин пишется латинскими буквами, без `@`, пробелов и отображаемого имени канала.
> После копирования вкладку браузера можно закрыть — OBS подключится к чату сам по этой ссылке.

### 2. Вставьте ссылку в OBS

1. В OBS внизу откройте **Источники → ＋ → Браузер**.
2. Выберите **«Создать новый»**, назовите источник, например **«Анимации чата»**, и нажмите **ОК**.
3. В поле **URL** вставьте скопированную ссылку.
4. Укажите размер области: для анимации на весь экран — **ширина 1920, высота 1080**.
5. Нажмите **ОК** и перетащите источник в списке **выше игры**, чтобы анимации были видны.

### 3. Проверьте

Напишите в своём Twitch‑чате одно из слов:

**`привет` · `здарова` · `давай` · `имба` · `алё` · `лизка` · `лиза` · `лизочка` · `снайпер` · `тройка` · `пока`**

Анимация появится в OBS. Повтор того же слова может сработать не сразу: между анимациями есть короткая пауза от спама.

> **Не видно экран настройки?** Добавьте в конец адреса страницы `?setup=1` и откройте её заново.
>
> **Не работает?** Проверьте логин канала, что источник в OBS включён и находится выше игры, а в свойствах источника нажмите **«Обновить кэш текущей страницы»**.

## Установка проекта на GitHub Pages

### 1. Положите анимации в папку `asset`

Имена должны совпадать со списком внутри `index.html` полностью, включая русские буквы, пробелы и регистр. Этот список удобнее всего изменять локальным редактором `editor.html` — см. раздел «Локальный редактор анимаций».

```text
asset/
  алё.webp
  давай.webp
  имба.webp
  лизка лиза лизочка.webp
  пока.webp
  привет здарова.webp
  снайпер.webp
  тройка.webp
```

### 2. Опубликуйте на GitHub Pages

1. Создайте публичный репозиторий, например `twitch-chat-animations`.
2. Загрузите **содержимое этой папки** так, чтобы `index.html` и `app.js` оказались в корне репозитория, а WebP — в папке `asset`. Файл `editor.html` для работы OBS не обязателен: его можно держать только на своём компьютере или тоже загрузить в репозиторий.
3. Откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажмите Save.
5. Через 1–3 минуты появится адрес вида:

```text
https://ВАШ_ЛОГИН.github.io/twitch-chat-animations/
```

Файл `.nojekyll` уже включён. Красивая страница с пользовательской инструкцией после публикации будет доступна по адресу `https://ВАШ_ЛОГИН.github.io/twitch-chat-animations/instruction.html`.

### 3. Подключите канал в OBS

Откройте опубликованный адрес и дальше следуйте короткой **«Инструкции для пользователя»** в начале этого файла: впишите канал, нажмите «Слушать», скопируйте ссылку и добавьте её в OBS как источник «Браузер».

Пара технических заметок: анимация вписывается в область Browser Source целиком и сохраняет пропорции; стандартный Custom CSS OBS с прозрачным фоном стирать не нужно. Если источник должен реагировать даже на сценах, где он не виден, не включайте «Shutdown source when not visible»: выгруженная страница чат не слушает.

## Как работают триггеры

По умолчанию слова берутся из имени файла без `.webp`. Пробелы, дефисы и подчёркивания разделяют альтернативные слова:

| Файл | Сработает на слова |
|---|---|
| `алё.webp` | алё, але |
| `давай.webp` | давай |
| `имба.webp` | имба |
| `лизка лиза лизочка.webp` | лизка, лиза, лизочка |
| `пока.webp` | пока |
| `привет здарова.webp` | привет, здарова |
| `снайпер.webp` | снайпер |
| `тройка.webp` | тройка |

Сопоставление идёт по целым словам, поэтому `пока` не сработает внутри слова «показать». Знаки препинания игнорируются: «привет!» тоже сработает. Одно сообщение запускает не больше одной анимации.

### Свои слова для файла

Слова задаются в редакторе `editor.html` в карточке файла через запятую:

```text
давай, поехали, добрый вечер
```

Здесь `давай` и `поехали` — отдельные альтернативные триггеры, а `добрый вечер` — целая фраза: она сработает только когда оба слова идут подряд.

## Локальный редактор анимаций

В проекте лежит отдельный файл **`editor.html`**. Это полностью локальный редактор: он не отправляет файлы в интернет, а изменяет блок настроек внутри основного **`index.html`**. Движок `app.js` при добавлении анимаций трогать не нужно.

### Добавить новую анимацию через редактор

1. Держите на компьютере папку проекта, где рядом лежат `index.html`, `app.js`, `editor.html` и папка `asset`.
2. Откройте `editor.html` в Chrome или Edge.
3. Нажмите **«Открыть папку проекта»** и выберите эту папку. Если браузер разрешает прямую запись, редактор сможет сохранить `index.html` на месте и сам скопировать новые WebP в `asset`.
4. Нажмите **«Добавить WebP…»** и выберите один или несколько файлов. Редактор сам предложит триггеры по имени файла, покажет превью, размер файла и длительность, если её удастся прочитать.
5. При необходимости исправьте триггер-слова в карточке. Несколько слов пишутся через запятую.
6. Проверьте фразу в блоке «Проверка слов» внизу редактора.
7. Нажмите **«Сохранить в index.html»**.
8. Загрузите на GitHub изменённый `index.html` и новые файлы из `asset`. Если после загрузки OBS показывает старую версию, нажмите Refresh cache в свойствах Browser Source.

Если редактор открыт двойным щелчком как обычный локальный файл, а браузер запрещает прямую запись в папку, редактор сам перейдёт в безопасный режим: нажмите **«Скачать index.html»**, замените скачанным файлом `index.html` в папке проекта и вручную скопируйте новые WebP в `asset`. Дальше на GitHub загружаются те же изменённый `index.html` и новые файлы из `asset`.

В редакторе также можно:

- нажать **«Найти WebP в asset»**, если файл уже лежит в папке, но его ещё нет в списке;
- удалять карточки и менять порядок анимаций стрелками;
- менять канал по умолчанию, кулдауны, очередь и игнорируемых ботов;
- задать отдельной анимации точную длительность и число повторов цикла.

> Если открываете старую папку проекта, где настройки ещё лежат в `config.js`, редактор сам прочитает этот файл и при первом сохранении перенесёт настройки внутрь `index.html`. После этого `config.js` можно удалить из репозитория — новая версия его не использует.

Статическая страница на GitHub Pages не может сама получить список файлов папки, поэтому новая анимация должна быть записана редактором в `index.html`. Просто положить WebP в `asset`, не добавляя карточку в редакторе, недостаточно.

## Длительность показа

Страница пытается прочитать длительность одного цикла из метаданных Animated WebP и скрыть файл после полного проигрывания. Если отдельная анимация обрезается или успевает повториться, укажите ей точную длительность в секундах в карточке редактора `editor.html`.

Если метаданные прочитать не удалось, используется общая «Длительность по умолчанию» из настроек — изначально 5 секунд.

## Защита от спама

Настройки изменяются в `editor.html` и сохраняются внутри `index.html`:

- `globalCooldownMs` — пауза после одной анимации перед следующей;
- `sameAnimationCooldownMs` — повтор той же анимации не раньше, чем через это время;
- `perUserCooldownMs` — один зритель не запускает анимации чаще этого интервала;
- `maxQueue` — максимум анимаций в очереди, остальное отбрасывается;
- `ignoredUsers` — боты и другие ники, чьи сообщения игнорируются.

Если обычные слова срабатывают слишком часто, поставьте `commandsOnly: true` или добавьте `&commandsOnly=1` в OBS-ссылку. Тогда нужны сообщения вида `!привет`.

## Параметры URL

| Параметр | Пример | Что делает |
|---|---|---|
| `channel` | `?channel=ваш_логин` | Twitch-канал для прослушивания |
| `setup` | `&setup=1` | Показать экран настройки и тест-чат |
| `scale` | `&scale=75` | Размер анимации в процентах области источника |
| `fit` | `&fit=cover` | `contain` — вписать целиком, `cover` — заполнить с обрезкой |
| `align` | `&align=bottom` | `center`, `bottom`, `top`, `left`, `right` |
| `durationMs` | `&durationMs=6000` | Длительность по умолчанию, если не прочиталась из WebP |
| `commandsOnly` | `&commandsOnly=1` | Только сообщения с `!` |
| `cooldownMs` | `&cooldownMs=1000` | Пауза между анимациями |
| `sameCooldownMs` | `&sameCooldownMs=30000` | Кулдаун одной и той же анимации |
| `userCooldownMs` | `&userCooldownMs=20000` | Кулдаун одного зрителя |
| `queueMax` | `&queueMax=2` | Максимальная очередь |
| `autoDuration` | `&autoDuration=0` | Не читать длительность из WebP |
| `ignore` | `&ignore=bot1,bot2` | Добавить игнорируемые ники |

## Про размер ваших файлов

Восемь файлов в сумме занимают около 80 МБ. Для GitHub Pages это допустимо, каждый файл меньше лимита загрузки через веб-интерфейс, но есть практический нюанс: страница **не загружает все анимации заранее**. Конкретный WebP скачивается при первом срабатывании, поэтому первый показ большого файла может начаться с задержкой; дальше OBS/Chromium использует кеш.

Если задержки будут заметны, сильнее всего поможет пережатие WebP: ориентируйтесь примерно на 1–3 МБ на анимацию, уменьшив разрешение и FPS до реально видимых на стриме.

## Проверка и проблемы

| Симптом | Что проверить |
|---|---|
| Открывается экран настройки вместо прозрачного фона | В ссылке OBS нет `?channel=...` или остался `setup=1` |
| Статус не становится «слушаю» | В `channel` нужен логин из `twitch.tv/ЛОГИН`: строчные латинские буквы, цифры и `_`, без `@` и пробелов |
| В тесте плашка «файл пока не найден» | WebP нет в репозитории, он лежит не в `asset`, либо имя файла в редакторе/`index.html` отличается хотя бы одной буквой/пробелом |
| Новая анимация не срабатывает | Проверьте в редакторе блок «Проверка слов»; затем убедитесь, что на GitHub загружены и изменённый `index.html`, и сам WebP в `asset` |
| Слово один раз сработало и дальше молчит | Это кулдауны из настроек; для проверки используйте другое слово или кнопку «Тест» на странице — она кулдауны обходит |
| Анимация обрезается или зацикливается | Задайте этому файлу точную длительность в карточке редактора |
| На другой сцене OBS не реагирует | Включено «Shutdown source when not visible» — страница выгружена и не слушает чат |
| GitHub Pages показывает старую версию | Подождите деплой на вкладке Actions; в OBS нажмите Refresh cache в свойствах Browser Source |

Для диагностики откройте ту же ссылку в обычном браузере и добавьте `&setup=1`: там видны статус Twitch, журнал срабатываний, тест-чат и кнопки каждой анимации.

## Структура

```text
index.html        — страница для OBS, экран выбора канала и встроенный список анимаций
instruction.html  — красивая короткая инструкция для пользователя
editor.html       — локальный редактор анимаций и триггеров; изменяет index.html
app.js            — Twitch-клиент, поиск слов, очередь показа
asset/       — ваши Animated WebP
.nojekyll    — отключает обработку Jekyll на GitHub Pages
```

> Никогда не кладите Twitch OAuth-токены в этот репозиторий: GitHub Pages публичен, любой сможет их прочитать. Для данного проекта токены и не нужны.
