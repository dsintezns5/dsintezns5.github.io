## 1. Что за сайт

Сайт стримерши с её билдами и гайдами Path of Exile. Целевая аудитория — люди, которые хотят влиться в PoE, но сложность игры их пугает.

## 5. Решения (Q&A с пользователем, 17.10.2026)

- **Хостинг:** GitHub Pages, репо `dsintezns5.github.io`, сайт в корне домена.
- **Рабочий процесс контента:** стримерша присылает новую информацию об билде → ИИ-агент обновляет файлы в git → GitHub Actions пересобирает и деплоит сайт (1–2 минуты). **CMS (Decap/Tina) не нужна.** Контент = чистый Markdown + YAML frontmatter, один файл на билд, структура предсказуема для агента.
- **MVP (цель — успеть к старту новой лиги):**
  1. Главная: приветствие, таймер до лиги, блок «Рекомендуемый билд на лигстарт», сетка билдов, блок «Ты впервые в PoE? Начни сюда»
  2. Каталог билдов: карточки + клиентские фильтры (класс/возвышение, сложность, бюджет, роль)
  3. Страница билда: «Быстрый старт», большая кнопка «Скопировать PoB», прогресс по стадиям (акты → белые карты → красные → уберы), гемы/экип/дерево, пометка версии лиги + даты обновления
  4. 2–3 демо-билда заглушками (помеченные «демо»), реальный контент подставится потом
- **Дизайн:** тёмная тема + фирменные цвета (🟡 не присланы — сделаю временную палитру, все цвета в одном месте/теме для быстрой подмены).
- **НЕ в MVP (этап 2):** комментарии (Giscus отложен — логин через GitHub барьер для RU-аудитории, вопросы вести в Discord/TG), квиз «выбери билд», глоссарий со всплывашками, чеклист прогресса, Twitch-виджет, зал славы, калькулятор резистов, цены poe.ninja.
